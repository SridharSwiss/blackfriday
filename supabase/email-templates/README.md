# Supabase email templates (AKTION.CH)
Generated by `npm run emails`. In Supabase: Authentication > Emails > Templates, paste the HTML and set the subject.

- magic-link.html — subject: "Your AKTION.CH sign-in link"
- confirm-signup.html — subject: "Welcome to AKTION.CH, confirm your email"
- change-email.html — subject: "Confirm your new AKTION.CH email address"
- reset-password.html — subject: "Reset your AKTION.CH password"
- reauthentication.html — subject: "Your AKTION.CH confirmation code"

Mapping: Reset Password = forgot-password link; Magic link = existing users signing in; Confirm signup = first sign-in of a new user; Change email address; Reauthentication.
Sender: use a verified Resend domain (SPF + DKIM + DMARC) with a from name of "AKTION.CH".
