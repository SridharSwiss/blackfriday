# Supabase email templates (AKTIONS.CH)
Generated by `npm run emails`. In Supabase: Authentication > Emails > Templates, paste the HTML and set the subject.

- magic-link.html — subject: "Your AKTIONS.CH sign-in link"
- confirm-signup.html — subject: "Welcome to AKTIONS.CH, confirm your email"
- change-email.html — subject: "Confirm your new AKTIONS.CH email address"
- reset-password.html — subject: "Reset your AKTIONS.CH password"
- reauthentication.html — subject: "Your AKTIONS.CH confirmation code"

Mapping: Reset Password = forgot-password link; Magic link = existing users signing in; Confirm signup = first sign-in of a new user; Change email address; Reauthentication.
Sender: use a verified Resend domain (SPF + DKIM + DMARC) with a from name of "AKTIONS.CH".
